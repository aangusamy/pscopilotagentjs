# pscopilotagentjs
Peopelsoft Copilot agent widget in js

## Files

| File | |
|---|---|
| `pscopilotagent.js` + `pscopilotagent_iscript` | Copilot Studio chat widget (Direct Line) |
| `psagent.js` + `psagent_iscript` | **PeopleSoft Agent** widget: chat that performs tasks on screen (create user profile, …) |
| `agent-service/` | Python service (Claude) behind `psagent.js`. Setup, tasks and tests are in [agent-service/README.md](agent-service/README.md) |
